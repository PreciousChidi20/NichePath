# NichePath hackathon demo

## Preparation

Run the production build/start instructions in README, or use a verified public deployment only after publication approval. Use synthetic text only. Start on the homepage with empty input, set the browser to a 360px viewport for a short mobile demonstration, then switch to desktop if useful. Have the financing summary visible/selectable as a fallback if clipboard permission is denied. Do not describe unreviewed references as verified citations.

## Three-minute script

| Time | Action | Suggested narration |
| --- | --- | --- |
| 0:00–0:20 | Show home, privacy notice and supported subjects. | “I developed NichePath from my experience studying an online MPH. Broad coursework can make specific interests hard to recognise. This standalone companion connects academic concepts to practical exploration.” |
| 0:20–0:45 | Enter `risk pooling and health insurance`; click **Find connections**. Show the suggestion, then explicitly choose **Explore Health Systems**. | “This MVP matches curated phrases in browser memory. It suggests a connection and asks the learner to confirm; it does not claim AI understanding.” |
| 0:45–1:10 | Show the selected **Risk pooling and insurance** concept and open **Health financing** using **Explore this niche**. | “A broad subject becomes a more specific interest. Insurance and risk pooling are related but distinct concepts; the guidance is starter material requiring review.” |
| 1:10–1:45 | Show **Where it is applied**, **Skills to explore**, **Follow the money**, reflection and **Keep your curiosity moving.** | “The learner sees practical applications, explained skills, an achievable hypothetical exercise and a concrete next-step output. We are helping them try an interest, not guaranteeing a career.” |
| 1:45–2:05 | Show illustrative pathways and **Sources to review**. Use **Copy next steps**, or **Select summary** if copying is denied. | “The portable summary contains curated guidance and review warnings, never the submitted excerpt. Proposed sources remain explicitly review-required.” |
| 2:05–2:25 | Follow the related Health leadership and governance link; return home. | “Curated relationships let curiosity move between niches. Across the MVP there are five MPH subjects and eleven starter niches.” |
| 2:25–2:45 | Enter `epidemiology and health systems`; show choices. Then try `marine biology`; show unsupported feedback and shortcuts. | “Ambiguous inputs need learner choice. Unsupported topics get an honest limitation and a useful way forward.” |
| 2:45–3:00 | Close with the track and collaboration explanation. | “Guidance comes from curated explanations; pathways from concrete activities and next steps; opportunity from exploring relevant domains without promising jobs. I supplied the concept and product decisions; Codex assisted with implementation, testing and delivery preparation, documented with evidence in our collaboration log.” |

The activity is a take-away exercise, not something to complete during the three-minute demo. No live AI, LMS, authentication or external API is needed. Avoid claims of source verification, semantic intelligence or accessibility certification.

## Rehearsal checklist

- [ ] Production server responds; confirm the deployed/local build is the intended revision.
- [ ] Risk-pooling input → confirmed Health Systems → financing works.
- [ ] Financing displays applications, explained skills, activity/reflection, concrete output, illustrative pathways and source-review notes.
- [ ] Copy or select the curated summary; excerpt is absent and review notes remain.
- [ ] Related governance navigation works; home input is cleared.
- [ ] Ambiguous and unsupported examples show the expected messages; direct subject shortcuts remain usable.
- [ ] 360px layout and keyboard focus are usable; no personal/sensitive examples are used.
- [ ] Know the limitations: starter content/manual source review, deterministic matching, Chromium-focused automated QA, no public deployment established by this preparation.
